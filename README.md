### Архитектура
* Классы сущности (модель)- мяч, кирпич, ракетка, игровое поле, настройки игры
* Игровой движок
* Генератор уровней
Для запуска игры на разных платформах упаковывать в загрузчик (jpackage)

### Работает все через меню
* В меню работаю стрелки и wasd
    * верх/низ- выбор параметра
    * лево/право- изменение значения
    * enter/space- старт
* В игре также wasd:
    * движение ракетки
    * пробел- старт игры (отпустить мяч от ракетки)
    * p- или esc- пауза
    * r- быстрый перезапуск
    * m- выход в меню

### Движок
* Проверка была ли нажата клавиша (спользовать коды клавиш, учесть зажатие)
* Цикл
    * учесть движение ракетки в пределах ширины поля (если статус игры READY то координаты мяча смещать вместе с ракеткой)
    * перемещение мяча (по счетчику или таймеру) + рикошет
        * стены (инверсия dx/dy мяча)
        * кирпичи проверка соседних клеток по x y (удар сбоку/верх/низ/угол)
        * ракетка. края отбивают в стороны (инверсия по x и y, центр- вертикально вверх, движение ракетки в момент удара подкручивает x мяча)
    * кирпичи идут вниз (таймеру/счетчику + настройка скорости)
    * убить/повредить кирпич при касании + начисление очков
    * конец игры (мяч коснулся дна-> вычитаю жизнь, нет жизни (0) или кирпичи коснулись дна- то проигрыш, а если все кирпичи уничтожены то победа и переход на след уровень)
* Отрисовка актуального состояния (меню настроек или сборка и отрисовка поля (двумерного массива))

### Создание уровней
* Количество рядов кирпичей (от 3 до 12)
* Плотность заполнения и полости (40 до 90 проц)
* Процент крепких кирпичей (0 до 50 проц)
* Наличие боковых коридоров по краям (да/нет)
* Скорость движения кирпичей (медл/норм/быстро)
* Скорость мяча (медл/норм/быстро)

### Свойства мяча
* Координаты (x/y)
* Его символ (0)
* Скорость (на сколько клеток сдвигать за один игровой шаг цикла)- dx, dy (dx (-1,0,+1) dy только +1 или -1)

### Свойства ракетки
* Координаты (меняется только x, y соответсвует дну поля)
* Размер (например 5 клеток)
* Символ (например = )
* Направление движения (-1 лево, 0 стоит, 1 право)

### Свойства кирпича
* Координаты (размер 1 клетка)
* Символ (например # обычный, @ крепкий)
* Свойство- крепкий/обычный (счетчик сколько нужно ударов до разрушения)
* Количество очков за разрушение/повреждение(касание)

### Свойства игрового поля
* Размеры (30 * 25 клеток)
* Символ
* Ссылки на зависимые объекты (ракетка, мяч, список кирпичей)
* Счет
* Количество жизней
* Статус (MENU, READY, PLAYING, PAUSED, GAME_OVER, VICTORY)
